How to Play

Climb from START to TARGET by changing exactly one letter each step. Every step must be a real word.

  • Example: CAT → COT → DOT → DOG
  • Tap letters or type, then press Enter. One letter different only!
  • Beat the timer for bonus points. Streaks multiply your score.
  • Use Hint if stuck, Undo to backtrack.
  • 3 letters = quick party, 4-5 letters = brain burner.
