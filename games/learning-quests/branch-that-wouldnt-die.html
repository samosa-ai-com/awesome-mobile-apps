📖 Field Guide of Rites

Kept by the Graveyard Keeper. Read before you cut.

🌙 The Three Omens

  • merged-quiet Branch is complete, tests pass, ready to join trunk. Rite: Fold-In (merge). The branch becomes part of history.
  • drifting-behind Trunk moved ahead — branch is behind by commits. Rite: Replay (rebase) to replay its commits on the new tip. Never Fold a drifter or you summon conflicts!
  • abandoned No commits, no keeper, forgotten experiment. Rite: Prune (delete) to clear the graveyard.

🩸 Scar Rule (Level 3+)

A scar means the branch was already folded into trunk — you can see the bark healed over. Even if it says merged-quiet, the correct rite is Prune, not Fold-In. Folding twice angers the tree.

🎮 How to Play

  • Tap a branch on the gnarled tree to open its rite menu.
  • Choose Fold-In / Replay / Prune according to the omen + scar.
  • Correct: +100 points. Wrong: -30 and the branch shudders.
  • Clear all branches to unlock Next Rite. Time bonus on completion!
  • Scars appear from Level 3 — always check bark first!

🔊 Git → Graveyard

  • Fold-In = git merge feature — creates a merge commit
  • Replay = git rebase main — replays commits cleanly
  • Prune = git branch -d feature — deletes the branch

Tip: In real git, rebase rewrites history — only replay branches you haven't shared. The graveyard forgives; your teammates may not.
