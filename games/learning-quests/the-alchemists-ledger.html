🌿 Field Guide

let vs const • types • vials

🏷️ What is a variable?

A labeled vial that holds one value. The label is the name, the liquid is the value, and the color tells you the type.

let luna = 12; means: create a reassignable vial called luna and pour 12 into it.

🎨 Typed Essences

Every ingredient has a type. A vial only accepts its matching type — just like in code.

  • Number — teal • 12, 3.14
  • String — lavender • "moon", 'herb'
  • Boolean — rose • true / false

Pouring a string into a number vial fizzles — type mismatch!

🟢 let — Reassignable

Open vial. Pour, pour again. The old brew is replaced.

let x = 1; x = 2;

🔴 const — Sealed

Wax-sealed. First pour locks it. Refills are rejected with a shake.

const y = 1; y = 2; // ❌

⚗️ How to play

  • 1. Tap an ingredient in the Pantry to pick it up.
  • 2. Tap a vial on the shelf to pour.
  • 3. Watch the Live Parchment update to real code.
  • 4. Use Undo if you mis-pour.
  • 5. Hit Check Brew to complete the recipe.

💡 Why sealed vials?

const protects important values — like a recipe's base or a potion's true name. If it could change by accident, the whole brew fails. Sealing makes your intent clear.
