How it’s built — no external 3D

This mini-app is 100% inline — no CDN, no Three.js, no images. It runs offline as a single HTML file.

1) 3D without external requests

  • Canvas 2D only Custom perspective projection: camera eye → target, basis vectors (right/up/forward), then xCam·f / zCam to NDC → screen.
  • Each block is 8 vertices → 6 faces. Faces are projected, depth-sorted (painter’s algorithm) and drawn with flat shading (top lighter, sides darker) for chunky toy look.
  • Sky is CSS gradient; clouds are 2D ellipses drawn before 3D to avoid extra geometry.

2) Controls

  • Touch: left joystick (118px base, 56px stick, 45px radius) → normalized vector → world velocity. Right 92px JUMP button. Both use touch-action:none and prevent scroll.
  • Keyboard: Arrow/WASD + Space. Input merged, clamped to unit circle, camera-relative lerp for smooth feel.
  • Large targets, 14px+ text, max-width 428px, no horizontal scroll — portrait mobile-first.

3) Physics (arcade, not rigid-body)

  • Gravity 26, jump impulse 10.5, max fall -18. Horizontal speed 6.2, lerp 0.18 for responsiveness.
  • AABB top-collision only: if previous bottom ≥ platform top and current bottom ≤ top + overlap, snap to top, zero vy, grounded.
  • Spinning bars: line-segment distance check in XZ plane → knockback + bounce. Beams: narrow AABB requires precise landing.
  • Fall threshold = checkpointY - 12 → respawn, increment drop counter.

4) Persistence

  • localStorage keys: skyBlocks_bestTime, skyBlocks_highestCP, skyBlocks_summits. Best time is lowest summit time; highest checkpoint unlocks stage label.
  • Timer starts on first input, stops at summit. Summit badge glows and persists.

5) Performance tips

  • ~18 platforms → ~108 faces/frame, sort O(n log n) trivial for mobile.
  • Cap dt at 33ms, use requestAnimationFrame, avoid allocations in loop (reuse vectors).
  • All CSS/JS inline, <60KB, no external fonts/images — instant load in WebView.
