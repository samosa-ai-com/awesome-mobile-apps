How it works & HTML structure

This is a mobile-first, single-button game. Everything fits 360–428px portrait with no horizontal scroll.

<div class="app"> // 428px max, centered <header> Best badge + logo <section.stats> Time | Clicks | CPS <div.center> <div.hint> status text <div.smash-wrap> <svg.progress-ring> 5s circle <button.smash-btn> 220px touch target <div.footer> Reset / Help / Start <div.overlay> Game-over summary + confetti </div>
  • .smash-btn is 220px (≥48px target) with touch-action:manipulation to prevent double-tap zoom.
  • Timer uses performance.now() + requestAnimationFrame for accurate 5.00s countdown.
  • Score + best saved in localStorage.smashBest and restored on load.
  • Live stats update on every tap: count + CPS = clicks / elapsed.
  • New record triggers confetti + gold badge + haptics.

Tip: Use two thumbs or alternate fingers for max CPS. The button counts pointerdown so it’s instant.
