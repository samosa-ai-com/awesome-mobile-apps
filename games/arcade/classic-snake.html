📘 Implementation Guide — Single-File Mini-App

This game is one self-contained HTML file with inline <style> and <script>. No external CDNs, no build step. Perfect for Android WebView / Masala mini-apps.

  • Layout: Mobile-first container max-width:428px (covers 360-428px portrait). Flex column, 100dvh, no horizontal scroll. All touch targets ≥44px.
  • Board: 20×20 grid on a <canvas>. Canvas size = CSS size × devicePixelRatio for crisp retina. Cell = canvas.width / 20.
  • Game loop: requestAnimationFrame + delta timer. Base tick 120ms, -6ms per level (min 55ms). Level = floor(score/5)+1.
  • State: snake:[{x,y}], dir/nextDir, food:{x,y}, score, best, isPlaying, isPaused. Persist best via localStorage.getItem('glossySnakeBest').
  • Input: Arrow keys + WASD + swipe (touchstart→touchend delta, threshold 18px) + D-pad buttons. Prevent 180° reverse.
  • Collision: Wall = out of bounds → game over. Self = head overlaps any segment. Food = head equals food → grow (don't pop tail), spawn new food not on snake.
  • Rendering: Glossy look via gradients, inner shadows, rounded rects. Snake head has eyes + highlight; body has gradient + shine dot. Food is radial apple with leaf.
  • Audio: WebAudio beeps (no files) — eat, level-up, crash.
  • Persistence: localStorage for best score. One-tap restart resets state without reload.
<meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no"> <canvas id="c"></canvas> <script> // tick = 120 - level*6 // if (head.x<0||head.x>=20||head.y<0||head.y>=20) gameOver() // if (snake.some(s=>s.x===head.x&&s.y===head.y)) gameOver() // localStorage.setItem('glossySnakeBest', best) </script>
