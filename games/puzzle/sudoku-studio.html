How to Play

Goal: Fill 9×9 so each row, column and 3×3 box contains 1-9.
Diagonal (5-8): Both main diagonals also 1-9 (purple tint).
Cage (9-12): Dashed cages show sum — numbers in cage must add to that sum (no repeat in cage).
Notes: Toggle Note to place pencil marks for candidate elimination.
Stars: 3★ = 0 mistakes, 2★ = 1 mistake, 1★ = 2 mistakes. 3 mistakes = fail.
Hint: Highlights the most constrained empty cell.
Undo/Redo: Full stack. Timer and mistakes save automatically.
