HOW TO PLAY

Goal: starting from the green assigned port, tap directly linked stations to traverse every route exactly once in a single run (Eulerian trail).

Rules: you can only move to adjacent stations via an unused route. Covered routes glow cyan. You must use all routes — no repeats, no skips.

Tools: Undo steps back (breaks flawless), Hint highlights one safe next station that keeps a solution possible, Reference animates the optimal trail.
