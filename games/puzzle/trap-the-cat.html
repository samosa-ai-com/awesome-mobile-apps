💡 Tap light tiles to block them (×). After each block the cat moves 1 step toward the edge. Trap it before it escapes! The cat thinks 3 moves ahead.

How to Play

• Hex grid — cat starts in center.
• Tap any light tile to block it. Cat then moves 1 hex toward the nearest edge.
• Cat uses BFS to find shortest path and dodges your blocks.
• Trap = cat has no moves. Escape = cat reaches red border.
• Reset retries same board, New Game randomizes blocks.
• Undo takes back your last block + cat move.
