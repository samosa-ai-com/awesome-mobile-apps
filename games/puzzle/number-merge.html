Mobile-first (360–428px portrait)

  • <meta viewport="width=device-width, initial-scale=1, user-scalable=no"> — no zoom needed, text ≥12px readable.
  • Container max-width:428px; min-width:360px centered, overflow-x:hidden — no horizontal scroll.
  • Grid uses display:grid; aspect-ratio:1 + gap:9px — scales fluidly.
  • All touch targets ≥48px (min-height:48px, D-pad 48×48) with touch-action:manipulation.

Pastel system

  • Background #FFF8F0, grid #E8E0D8, cells #F6F1EB.
  • Tiles: 2 #FFE4E6 → 2048 gradient #FFD166→#FF8FA3 with white border.
