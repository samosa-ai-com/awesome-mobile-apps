How to Play & Build It

This is a mobile-first quiz for 360–428px portrait. Two large buttons, no horizontal scroll, 16px+ text, 52px+ touch targets.

1) HTML Structure (what you see)

<div class="app">  <!-- max-width:428px, centered -->
  <header> Score / Streak / Best </header>
  <div class="progress"><i></i></div>
  <div class="cards">
    <button id="btnA"><span id="numA"></span></button>
    <div class="vs">VS</div>
    <button id="btnB"><span id="numB"></span></button>
  </div>
  <div id="feedback"></div>
  <div class="controls">
    <button id="restartBtn">Restart</button>
  </div>
</div>
  • .app { max-width:428px; min-width:360px; height:100dvh; overflow:hidden } prevents horizontal scroll.
  • Buttons are min-height:124px with touch-action:manipulation for instant taps.
  • All text ≥13px, question 15px, numbers 48px — readable without zoom.

2) JS Logic — Scoring / Streak / Restart

let score=0, streak=0, best=+localStorage.best||0;

function newRound(){
  let a = rand(), b = rand();
  while(b===a) b = rand(); // ensure different
  numA.textContent=a; numB.textContent=b;
  // store correct answer
  correct = a>b ? 'A' : 'B';
}

function pick(choice){
  if(choice===correct){
    score++; streak++;
    best = Math.max(best,streak);
    feedback("Correct! +1","ok");
  } else {
    streak = 0; // reset streak, keep score
    feedback("Wrong! Streak reset","bad");
    // optional: score = Math.max(0,score-1)
  }
  save(); updateUI(); newRound();
}

restartBtn.onclick = () => {
  score=0; streak=0;
  feedback("New streak started!","ok");
  updateUI(); newRound();
};
  • Scoring: +1 per correct tap. Streak increments only on correct.
  • Streak: resets to 0 on wrong answer; best saved in localStorage.
  • Restart: zeroes score & streak, keeps best, generates new numbers.
  • Rush mode: 30s setInterval countdown; when 0, freeze input until Restart.

3) Tips for 360–428px

  • Use flex:1 + max-height for cards so they fill height without scrolling.
  • Viewport: width=device-width, initial-scale=1, user-scalable=no
  • Test at 360px and 428px — no element wider than 100%.
